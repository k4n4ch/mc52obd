# ギヤ判定と車速補正

**走行中モニタ（`index.html`）とログビュワー（`map.html`）で同じ方式を使う。**
ログにギヤ列は持たせず、毎回 `rpm` と `speed_obd` の生値から判定し直す。理論減速比を
軸に単一のスケール係数 `k` を当てる。`localStorage` で両アプリが共有するのは
**判定窓と車速のトリム**だけ。

スプロケット 14T → 15T が走行余力に与える影響は [GEARING.md](../GEARING.md)、
実測の根拠は [FINDINGS.md](../FINDINGS.md)。

## 比推定で段を出す

**ギヤポジションは比推定で表示する。** 理論減速比を軸に単一のスケール係数 k を当てる方式で、
`map.html` と同一。判定できない場合は理由を書き分ける。`–` は低速すぎて比が定義できない状態、
`⇅` は変速の最中（ビュワーのみ）、`?` は比は出たがどの窓にも入らない状態。妥当性を走りながら
見るのが目的なので、走行中モニタにヒステリシスは入れていない。

## k は較正しない

**k は較正しない。閉じた定数である。** k を構成するのは一次減速比・変速比（諸元）と ECU の
固定係数（ファーム定数）だけで、車速センサはファイナルより上流にあるため前後スプロケも
実タイヤも空気圧も摩耗も効かない。較正すべき自由度が存在しないので **k = 1.0057 で固定**
している（実測 5 走行 n=1554、新 3 本で 1.0055 / 1.0057 / 1.0064、幅 0.09%）。
ただしログから当てた値を設定（⚙）に併記するので、**前提が崩れれば気づける**（`0D` の切り捨てを
見つけたのがこの比較だった）。画面で変えられるのは判定窓だけ。

## 判定に課す 2 つの下限

判定には 2 つの下限を課している。

- **車速 8 km/h 未満は使わない。** 分母が小さすぎて比が暴れる
- **回転数 1,700rpm 未満は使わない。** クラッチを切って惰性で減速すると回転数がアイドル
  （約 1,400）に張り付き、車速との比が偶然どれかの段と一致する。6 速 22km/h の理論値が
  1,470rpm なので**比としては正しく合ってしまい、残差では弾けない**。車速下限があるため
  本物の 1 速でも最低 1,828rpm になり、アイドル上限との間に閾値を置けば正当な判定を失わない
  （実測で落ちるのは 0.66%、その 100% がスロットル全閉）

## 取得時刻のずれを揃える

**回転数は車速の取得時刻へ線形補間して揃える。** 両者は別リクエストなので取得時刻がずれ、
加速中は比が過大に、減速中は過小になる（実測 +7.3% / −5.8%、符号が加減速で反転する）。
`skew_ms` 列があればその値、無ければ中央周期で近似する。実ログでの効果はギヤ確定率
56% → 65%。設定（⚙）の「時刻補正」で on/off できる。

## 判定窓は段ごと・向きごとに独立させる

窓を `|比/予測 − 1| ≤ t` と定義すると、隣接する 2 段の窓が触れ合う条件は

```
r_a(1−t) = r_b(1+t)   →   t = (s−1)/(s+1)     s = r_a / r_b（隣接段の比）
```

これは**その 2 段の間でだけ**成り立つ上限で、段によって 3.5 倍違う。

| 段境界 | s | 触れ合う上限 |
|---|---|---|
| 1-2 | 1.5182 | 20.58% |
| 2-3 | 1.3636 | 15.38% |
| 3-4 | 1.2222 | 10.00% |
| 4-5 | 1.1578 | 7.31% |
| 5-6 | 1.1233 | **5.81%** |

**全段に同じ値を使うと、判定の厳しさが段ごとに 3.5 倍ばらつく。** 4.0% は 5-6速では境界までの
69% を許すのに、1-2速では 19% しか許さない。**一番余裕のある低速段で一番厳しく切っていた。**

そこで「境界までの何割か」を一定にする。設定値は最も狭い 5-6速での窓（＝従来と同じ意味）とし、
割合 `f = 設定値 / 5.81%` を他の境界へ適用する。保存済みの設定値がそのまま通り、上限
（`f = 1`、全境界がちょうど触れ合う）も意味を保つ。設定値 4.0% での実際の窓は以下。

| 段 | 上側（一つ下の段へ） | 下側（一つ上の段へ） |
|---|---|---|
| 1 | **4.00%**（隣なし） | 14.17% |
| 2 | 14.17% | 10.60% |
| 3 | 10.60% | 6.89% |
| 4 | 6.89% | 5.04% |
| 5 | 5.04% | 4.00% |
| 6 | 4.00% | **4.00%**（隣なし） |

**外側（1速の上・6速の下）には隣が無い**ので比例のしようがなく、設定値をそのまま使う。ここは
「隣の段と見分ける」問題ではなく「どの段にも嵌っていない」を弾く問題だから。**滑るクラッチは
エンジンを駆動系より速くする方向にしか働かない**ので、発進の半クラは必ず 1速の上側に出る。
実測でも、窓を広げた後に残る棄却 539 点のうち **281 点が 1速の上側**で、この固定が効いている。

**諸元から算出しているので車種を変えても手で直す必要は無い。** 入力欄の `max` に触れ合う上限を
設定し、超える値を打ち込んだら丸める。実際の窓にはこれに加えて車速の量子化ぶん `0.5/車速` が
乗る。

### 実測での効果（12 走行 28,967 行）

**確定 94.02% → 98.14%**（棄却 6.0% → 1.9%）。**既存のラベルは 1 つも変わらない** ——
割り当ては最近傍のままで、動くのは棄却閾値だけだから。

| 段 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 回復 | **+24.5%** | +13.8% | +4.7% | +0.9% | +0.4% | 0 |

**低速段に単調に集中し、6速でちょうどゼロになる。** 段の間隔が広い側ほど取りこぼしていた、
という予測どおりの形。回復した 1,194 点にスロットル全閉は 1 点も無く、惰性・クラッチ切りは
混じっていない。

## 変速の最中は `shift` として切り出す（ビュワーのみ）

判定できない行を**意味で分ける**方針（`stop` / `slow` / `unk`）に、変速過渡を 4 つ目として
足した。**これをやらないと `unk` が「正常な通過状態」と「k の前提が崩れている」の両方を
指してしまい、`?` が出ても意味を読めない。**

判定は後処理だからできる —— **前後の確定段が違い、かつ実時間で 2 秒以内**なら、その間は変速の
最中。時間で切らないと、停車や低速区間を挟んで段が変わっただけのものまで拾う（実測でそれが
棄却の 45% を占めた）。実ログでは 116 行、判定対象の 0.40%。地図では長い破線で描き、
凡例で「変速中」「半クラ」「低速」を分けている。

**走行中モニタには入れていない。** 先読みが要るうえ、「妥当性を走りながら見る」ために
ヒステリシスを入れないという方針に反する。あちらは変速中も近いほうの段をそのまま出す。
比が本当に段の間にあるので、**比だけを見て変速中と判るのは後処理でしか無理**。

## 表示車速の補正

ECU は純正 14T/36T を固定前提に換算するため、丁数を変えると `0D` が真の車速からずれる。
補正係数は `(前/14)×(36/後)` で、15T なら ×1.0714（実測の 1/0.935 = 1.0695 と 0.18% 一致）。
**補正するのは表示だけで、ログには ECU の生値を記録する。** 補正済みを記録すると設定を
間違えたときに戻せないため。ギヤ判定も生値の比で行う。

### 丁数の設定

**前丁数は 12-15T から選ぶ。既定は純正 14T、後は 36T 固定。** 走行中モニタはログボタンで
開くパネル、ビュワーは「⚙ 設定」の「前丁数」。設定は `localStorage` を共有しており、
どちらで変えても両方に効く。

**一度も触っていなければ保存しない。** 触っていないのに「設定済み」にすると、ビュワー側の
丁数自動推定（未設定のときだけ発火する）を潰してしまうため。

**補正が掛かるのは表示（グラフ・カーソル値・線の太さの区分）だけで、ギヤ判定には掛けない**
—— `k` は生値に対して定義されているため。実ログで 15T を選ぶと表示車速と GPS 速度の比が
1.000 になり、ギヤ確定率は丁数を変えても動かないことを確認済み。

### 表示車速は GPS より約 1.7% 高い

**表示車速は GPS より約 1.7% 高い。校正できる。** 丁数比 15/14 は諸元から決まる
理論値だが、実測の `0D`/GPS は丁数比だけの予測（14/15 = 0.9333）より **0.9% 高い**
（9 走行・GPS 10,739 点、45km/h 以上で比は 0.940〜0.944 と平ら。速度依存は無い）。
ECU の想定円周が実際の転がり円周より大きいためで、**タイヤの摩耗・空気圧で動く実在の量**。

**`k`（ギヤ判定）とは性格が違う。** `k` は諸元とファーム定数だけで決まり較正の自由度が
無いが、表示係数は実在する個体差を含む。そこで**既定は理論値のまま**にし、
ビュワーの「**車速校正**」で GPS から求めた**トリム**を掛けられるようにした。

- トリムは `localStorage`（`mc52_strim`）に入り、走行画面と共有される。既定は 1.000
- 校正には **45km/h 以上**の点だけを使う。`0D` の 1km/h 量子化と GPS のノイズで、
  低速側は比が上へ跳ねる（15〜29km/h 帯で 0.967、45km/h 以上で 0.940）
- **ギヤ判定には掛からない**（`k` は生値に対して定義されているため）
- この車両の実測値はトリム 0.9834、表示係数 1.0537

### 丁数推定

**「丁数推定」で GPS から自動入力できる。** 補正係数を `c = Σ(GPS) / Σ(0D)`（和の比。各点の
比を平均すると分母のノイズで上振れする）で測り、`丁数 f の係数 = f / 14` と突き合わせる。
GPS が信頼できる 20km/h 以上のみ使う。設定を保存していない状態で CSV を読むと自動で入り、
以後は手動で上書きできる（保存済みの設定を勝手に書き換えることはしない）。

### 丁数の選択肢は実際の品揃えに合わせてある（2026-08 調べ）

| | 設定 | 根拠 |
|---|---|---|
| 前（ドライブ） | **12-15T から選択** | サンスター 品番361 の設定歯数が 12-15T、キタコ `530-1818` は 13/14/15T。**16T 以上は存在しない**。15T でもスプロケットカバーへの干渉が報告されるほどで物理的に大きくできない |
| 後（ドリブン） | **36T 固定（選択肢なし）** | サンスター `RH-133` は **36T（純正歯数）のみ**、NTB `SPH-086R` も 36T。主要メーカーが他を出しておらず、選択肢にする意味が無い |

純正は 14T/36T、520 サイズ 108L。

**丁数の係数は 7.1% 刻みで、GPS の測定誤差 0.5% に対し一桁の余裕がある。** 実ログ 2 本とも
一位の 15T が誤差 -0.0% / 0.5%、次点の 14T が -6.7% / -6.2% と桁で離れ、推定が揺らぐ余地は
無い。補正後の車速/GPS は 0.9995 / 1.0048。

なお前後とも広いレンジ（前 12-18T / 後 28-48T）で総当たりしていた時期は、候補間隔が測定
誤差を下回って実車と違う組（17/41）が首位に来ることがあった。**探索範囲を実在する品揃えに
合わせることが精度の前提**になっている。
