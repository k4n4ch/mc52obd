# 独自層の信号マップ（MC52 / CB250R 2018）

**`tools/klmap.py` が `private/logs/*.bin` から生成する。手で編集しない。**
解釈（名前と根拠）はスクリプト内の `KNOWN` に置いてあり、そこだけが人の判断。

測定の経緯と根拠は [`FINDINGS.md`](FINDINGS.md)、プロトコルの仕様は
[`../firmware/SPEC.md`](../firmware/SPEC.md)。

## 読み方

| 種類 | 意味 |
|---|---|
| 1 | **定数。** その系に信号が来ていない |
| 2〜4 | **旗。** 状態を表す |
| 多い | **量。** 相関を見る |

相関は Spearman（順位相関）。`0x11` 内の rpm・車速は同一フレームなので厳密、
別テーブルとの相関は ±400ms で最も近いサンプルを当てたもの（被覆率を併記）。

## テーブル `11`

**センサ群。本命。** 先行事例（CRF250L）の配置がそのまま当たった。

先行事例に記載が無かった `[20]`〜`[23]` も同定した。**`[20]` は点火進角**で、標準層 `0E` と同じ符号化（アイドルで両者 9.5°）。**`[21]` と `[22-23]` は同じ量の粗／細**で、暖機で減る。始動直後は水温一定のまま時間で減るので、水温だけの関数ではない（始動後増量の減衰と読める）。**スケールは未確定**（アイドル回転数と同じ向きに動く: `[21]`=58 で 1542rpm、47 で 1412rpm）。

スロットルも標準層と同じ符号化で 2 系統あった —— **`[6]` が絶対（PID `11` 相当）、`[7]` が相対（PID `45` 相当）**。`[6]` はアイドル 10.2% / 最小 9.8% が標準層の実測と小数第 1 位まで一致した
