基板は [`../hardware/`](../hardware/)。**探索＋記録フェーズ用の窓なし箱。**
表示器が未決なので窓は付けていない。決まったら寸法を足して再出力する。

| | |
|---|---|
| 外形 | **54.8 × 44.8 × 22.6mm**（突起なし） |
| 内寸 | 50.8 × 40.8 × 17.6mm |
| 壁 / 床 / 蓋 | 2.0 / 2.5 / 2.5mm |
| ネジ | **M2 × 20mm を 3 本**（蓋・基板・本体を 1 組で締める）。**なべか六角穴。皿は不可**（ザグリが平底） |
| 車体固定 | タイラップの溝を底と蓋に 2 本（5 × 1mm）。帯が一周し、締めると蓋も押さえる |
| 材料 | **PETG**。PLA は Tg 約 60°C でシート下の夏に耐えない |

## 固定の考え方

**ネジ 1 組で蓋・基板・本体をまとめて締める。**

```
蓋の柱（上から 13mm 降りる）→ 基板の取付穴（素通し）→ 本体の柱にタッピング
```

基板が上下の柱に挟まれるので**基板専用のネジが要らず、蓋の固定点を基板の外へ出す
必要も無い。外形が基板＋壁だけで済む。**

**M2 を使う。** M2.5 の六角穴は逃げ半径 2.25mm を要求するが、取付穴から最寄り部品
までは 左上 2.55 / 左下 2.72 / 右上 2.96 / 右下 7.67mm しかない
（[`../hardware/README.md`](../hardware/README.md)）。φ4.0 の柱（半径 2.0）なら
4 隅とも 0.55mm 以上空く。

**蓋の柱は左下だけ省いて 3 本。** そこは `J1` の線が出る角で、ケーブルの U 溝と
0.2mm 食い合う。3 点で十分留まり、基板はその角も本体の柱に載る。

### 外形をここまで詰めた経緯

| | 外形 | 問題 |
|---|---|---|
| 初版 | 64.8 × 54.8 | 蓋のネジ柱を外殻に含めたため**外周が片側 7mm のソリッド** |
| 耳に変更 | 59.8 × 49.8 | **外へ飛び出した耳の根本が折れる**（積層方向に曲げが入る） |
| **現在** | **54.8 × 44.8** | ネジを基板の穴と共用し、突起も肉厚も無くした |

## 寸法の根拠（実測 2026-09-15）

```
C2（電解）の高さ      8mm
J1 の熱収縮まで      12mm   ← 内寸を支配する
線が曲がり始める     20mm
シースの下端         33mm   外径 6mm
```

**内寸を決めているのは `C2` ではなく `J1` の 12mm。** そして曲がり始めが 20mm なので、
ケース内で線を曲げようとすると内寸 22mm 以上になる。**蓋から真っ直ぐ抜いて外で
曲げれば 13mm で済み、外形で 9mm 低い。**

**シースは蓋を貫かない。** 33mm と高く、熱収縮を被せた端子 3 本が約 7.6mm 幅あって
内径 6mm のシースに入らないので下げられない。蓋を通るのはバラの 3 本。

## ケーブル出口は縁まで開いた U 溝

**閉じた長穴だと蓋が入らない。** 線は既に `J1` へハンダ付け済みで、蓋を上から通すには
ケーブルの反対端（4 ピンカプラ）を長穴に通す必要があるが、通らない。

組み立ては

1. 基板を本体の柱に載せる
2. **蓋を壁より 1.2mm 高く保って横へずらし、線を溝の口から入れる**
3. 1.2mm 落として縁を噛ませる
4. M2 × 20 を 3 本、蓋の上から締める

溝は `J1` の線が一列に並んでいる x 方向へ抜いてある（幅 4.6mm で済み、y 方向より
開口が小さい）。**樋は付けていない** —— シリコンを塗らない方針なので充填の深さが
要らず、付けると蓋の柱と反対を向いて印刷でサポートが要る。

## 干渉検査

**目視ではなく交差を取って確かめる。** レンダは当てにならない（柱が壁に溶けて
数え間違えた実績がある）。

```
python3 genparts.py      # 製造データから全 26 部品の外形を parts.scad へ起こす
for t in lid_wire lid_shrink lid_parts base_parts post_slot standoffs; do
  openscad -D 'PART="none"' -D "TEST=\"$t\"" -o /tmp/t.stl check.scad
done
```

「empty」が出れば干渉なし。**寸法を変えたら必ず回す。**

| 検査 | 内容 |
|---|---|
| `lid_wire` / `lid_shrink` | 蓋 × 線（φ2.5）/ 熱収縮（φ3.2、12mm まで） |
| **`lid_parts`** | **蓋の柱 × 実装される全 26 部品** |
| `base_parts` | 本体 × 全 26 部品 |
| `post_slot` | 蓋の柱が U 溝に削られていないか |
| `standoffs` | 本体の柱が 4 本とも在るか |

`genparts.py` が [`../hardware/Pick_Place`](../hardware/) と `jlc_bom.csv` から
外形を起こす。**蓋の柱は基板面まで 13mm 降りるので、XY で重なれば高さに関係なく
当たる。** だから高さの実測が無い部品も外形さえ分かれば検査できる。

### 検査で見つかった干渉

- **蓋の内側の縁を中実にすると `J1` の熱収縮に当たる。** 枠にすること
- **本体の柱を φ5.8 にすると `J1` の線と 0.17mm 干渉する。** φ4.8 に落として余裕 0.33mm
- **蓋の柱を左下に立てると U 溝と 0.2mm 食い合う。** その角だけ省いた

### 検査式そのものを間違えた例

- **柱の有無を円盤で突くと必ず欠ける** —— 柱には素通し穴が開いているため。穴と外周の
  間（半径 1.55mm）の円周上を突く
- `include` は元ファイルの最上位の出力文まで実行する。`-D 'PART="none"'` で殺す

## 仮組みプレート

**ネジが届くまでの繋ぎ。** 板＋スナップ足で基板を保持する（`mc52plate.scad`）。
基板高さ 5.5mm はケースと同じで、`J1` の裏ピンが逃げる。

| | |
|---|---|
| `mc52-plate-snap.stl` | 先端が 3 つに割れて弾性で嵌まる。掛かり 片側 0.30mm |
| `mc52-plate-press.stl` | 割らずに締まり嵌め（φ2.85）。**スナップが折れたらこちら** |

抜け止め（φ3.4）は基板の上に出るが、4 隅とも 0.85mm 以上空いている。
座（φ5.0）は基板の下なので実装部品とは無関係。

**割りの隙間が 0.8mm あるので、スライサの「隙間を埋める」系の設定が効くと足が
繋がる。** プレビューで 3 本の割りが見えているか確認する。抜けやすければ
`BARB_D` を 3.6 に、入らない・折れるなら 3.2 にする。

## 出力

```
brew install --cask openscad@snapshot     # 通常の cask は Gatekeeper で無効化されている（2026-09-01）
openscad -D 'PART="base"' --export-format binstl -o mc52-base.stl mc52case.scad
openscad -D 'PART="lid"'  --export-format binstl -o mc52-lid.stl  mc52case.scad
```

BambuStudio でスライスする。**蓋は外面を下にして置く**（柱が上を向いて自立する）。

## 未確認

- **PETG の Tg は約 80°C。** シート下・夏の直射で内部が 60〜70°C になる可能性はあり、
  余裕は大きくない。荷重がかからない箱なので即破綻はしないはずだが、心配なら ASA
- **防水はしていない。** 積層造形は素で水が通る。シリコンを塗る方針は一旦見送った
- 実機で嵌合を確認していない。**素板 3 枚が現物合わせ用にある**
