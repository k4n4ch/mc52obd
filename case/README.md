# ケース（PETG で 3D プリント）

基板は [`../hardware/`](../hardware/)。**探索＋記録フェーズ用の窓なし密閉箱。**
表示器が未決なので窓は付けていない。決まったら寸法を足して再出力する。

| | |
|---|---|
| 外形 | **54.8 × 44.8 × 22.6mm**（四隅の耳で最大 59.8 × 49.8、＋ケーブル樋 6mm） |
| 内寸 | 50.8 × 40.8 × 17.6mm |
| 壁 | **2.0mm**（0.4mm ノズルで 5 周）。床 2.5mm |
| 材料 | **PETG**。PLA は Tg 約 60°C でシート下の夏に耐えない |
| 基板固定 | M2.5 × 4（タッピング、下穴 φ2.1） |
| 蓋 | M2.5 × 4。基板の外側に出してある |
| 車体固定 | **タイラップの溝**を底と蓋の両方に 2 本（5 × 1mm）。帯が一周し、締めると蓋も押さえる |

## 寸法の根拠（実測 2026-09-15）

```
C2（電解）の高さ      8mm
J1 の熱収縮まで      12mm   ← 内寸を支配する
線が曲がり始める     20mm
シースの下端         33mm   外径 6mm
```

**内寸を決めているのは `C2` ではなく `J1` の 12mm。** そして曲がり始めが 20mm
なので、ケース内で線を曲げようとすると内寸 22mm 以上になる。**蓋から真っ直ぐ
抜いて外で曲げれば 13mm で済み、外形で 9mm 低い。**

**シースは蓋を貫かない。** 33mm と高く、熱収縮を被せた端子 3 本が約 7.6mm 幅
あって内径 6mm のシースに入らないので下げられない。蓋を通るのはバラの 3 本。

## ケーブル出口は縁まで開いた U 溝

**閉じた長穴だと蓋が入らない。** 線は既に `J1` へハンダ付け済みで、蓋を上から
通すにはケーブルの反対端（4 ピンカプラ）を長穴に通す必要があるが、通らない。

組み立ては

1. 基板を本体へ M2.5 × 4 で留める
2. **蓋を壁より 1.2mm 高く保って横へずらし、線を溝の口から入れる**
3. 1.2mm 落として縁を噛ませる
4. 蓋を M2.5 × 4 で留める
5. **樋にシリコンを充填**し、合わせ面にもビードを回す

溝は `J1` の線が一列に並んでいる x 方向へ抜いてある。幅 4.6mm で済み、
y 方向へ抜くより開口が小さい（塞ぐシリコンが少ない）。

## 干渉検査

**目視ではなく交差を取って確かめる。** `check.scad` が線・熱収縮・背の高い部品を
円柱と直方体でモデル化し、各部品との交差が空かを見る。

```
for t in lid_wire lid_shrink lid_parts base_shrink base_parts; do
  openscad -D 'PART="none"' -D "TEST=\"$t\"" -o /tmp/t.stl check.scad
done
```

「empty」が出れば干渉なし。**寸法を変えたら必ず回す。**

見つかった干渉の例:

- **蓋の内側の縁を中実にすると `J1` の熱収縮に当たる**（基板上面 18.6mm に対して
  縁の下端 18.4mm）。枠にすること
- **基板を受ける柱を φ5.8 にすると `J1` の線と 0.17mm 干渉する。** 取付穴
  (3.5,3.5) の中心から `J1` の 1 番ピン (2.54,7.62) まで 4.23mm しかない。
  φ4.8 に落として余裕 0.33mm。`hardware/README.md` の「M2.5 の頭でも余裕
  0.30mm」と同じ制約
- **蓋ネジの柱を外殻に含めると外周が片側 7mm の肉になる。** 四隅の局所的な耳に
  変えて、壁は 2.0mm。外形が 64.8 × 54.8 → 54.8 × 44.8（耳込み 59.8 × 49.8）
- **タイラップをトンネルにすると 2.0mm の壁を貫いてキャビティへ抜ける。**
  溝に変えて帯をケースの外周に一周させる

**レンダの目視は当てにならない。** 柱は壁から 1.5mm しか離れていないので、斜めから
見ると壁に溶け込んで 1 本しか判別できなかった（4 本とも在った）。`standoffs` の
検査はそれを数える。

## 出力

```
brew install --cask openscad@snapshot     # 通常の cask は Gatekeeper で無効化されている
openscad -D 'PART="base"' --export-format binstl -o mc52-base.stl mc52case.scad
openscad -D 'PART="lid"'  --export-format binstl -o mc52-lid.stl  mc52case.scad
```

BambuStudio でスライスする。**サポートは要らない**（蓋の樋は自立、本体は箱）。

## 未確認

- **PETG の Tg は約 80°C。** シート下・夏の直射で内部が 60〜70°C になる可能性は
  あり、余裕は大きくない。荷重がかからない箱なので即破綻はしないはずだが、
  心配なら ASA
- **積層造形は素で水が通る**（レイヤー間）。防水はシリコン頼み。防滴どまりの想定
- 実機で嵌合を確認していない。素板 3 枚が現物合わせ用にある
