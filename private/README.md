# private/

位置情報を含むログの置き場。**この配下は `private/README.md` を除いて git で追跡しない。**

スマホ GPS と連携した OSM 描画を行う際の生ログ、および Car Scanner 等スマホアプリの
エクスポート（位置情報列を含みうる）はここに置く。

リポジトリに残すのは解析結果のみ。生の軌跡は残さない。

## 取り込み

スマホから降ろしたログはブラウザのダウンロード先に溜まるので、`tools/importlogs.py` で
ここへ集める。CSV と同名の GPX は対で扱う。

```bash
python3 tools/importlogs.py            # 取り込む（元は残す）
python3 tools/importlogs.py --move     # 一致を確認してから元を消す
python3 tools/importlogs.py --list     # ここの中身を一覧する
```

**同名で中身が違うファイルは上書きしない。** 走行ログは撮り直せないので、衝突は報告だけ
して手を止める。

## 置いてあるもの

| 名前 | 中身 |
|---|---|
| `mc52_<日付>_<時刻>.csv` / `.gpx` | 走行ログの全尺。現行のファイル名 |
| `cb250r_<日時>.csv` / `.gpx` | 同上。2026-08 中頃までの旧いファイル名 |
| `seg*.csv` / `.gpx` | 全尺から切り出した区間（`tools/cutlog.py`）。**元ログから再生成できる** |

`tools/gearing.py --verify` と `--svg`（使用密度図）はここのログを読む。**全尺だけを見る**
ので、切り出した区間を置いても二重に数えられることはない。

`_bk` の付いたファイルは、アプリが記録中に途中経過を書き出していた頃の名残。全尺の先頭
部分と一致するので取り込まない。現在のアプリは下書きを IndexedDB に持つのでこの名前では
出てこない。
